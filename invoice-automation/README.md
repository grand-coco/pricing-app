# 請求書ツール 設定と使い方（初心者向け）

ヤフーメールに届く請求書をパソコンが毎日自動で集め、毎月20日に「送ってよいですか？」と確認してから税理士さんへ送ります。

```
毎日 10:00（パソコンの電源が入っていれば）
  └ ヤフーメールを確認 → 請求書を「請求書\今回送る分」フォルダに保存

毎月20日以降の最初の起動時
  └ フォルダを開いて確認メッセージを表示
       はい     → 圧縮して税理士さんへ送信、送ったファイルは「送信済み\○年○月分」へ移動
       いいえ   → 今日は送らず、明日もう一度聞きます
       キャンセル → 今月は送りません
```

---

## 最初に1回だけやる設定（30分くらい）

### 手順1　ヤフーメールで「外部からのアクセス」を許可する

ツールがメールを読んだり送ったりできるように、ヤフーメールの設定を変えます。

1. ブラウザでヤフーメールを開きます。
2. 右上の **「設定・その他」**（歯車のマーク）→ **「メールの設定」** を開きます。
3. 左のメニューの **「IMAP/POP/SMTPアクセスとメール転送」** を開きます。
4. **「Yahoo! JAPAN公式サービス以外からのアクセスも有効にする」** を選びます。
5. **IMAP** と **SMTP** を「有効」にして、**保存** を押します。

> SMSの確認コードだけでログインしている（パスワードを設定していない）場合は、先にYahoo! JAPAN IDのパスワードを設定してください。パスワードがないとツールからログインできません。

### 手順2　Python（パイソン）をインストールする

このツールを動かすための無料のソフトです。

1. ブラウザで **https://www.python.org/downloads/windows/** を開きます。
2. 「**Stable Releases**」の一番上にある「Python 3.14.x - ○○日付」の下の **「Download Windows installer (64-bit)」** を押します。
   （「Python install manager」という項目は使いません）
3. ダウンロードした `python-3.14.x-amd64.exe` を開きます。
4. ⚠ 最初の画面の下にある **「Add python.exe to PATH」にチェック** を入れます。
5. **「Install Now」** を押します。「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」を押します。
6. 「Setup was successful」と出たら **「Close」** を押します。
7. 確認：Windowsキーを押して「cmd」と入力し、コマンドプロンプトを開きます。`py --version` と入力してEnterキーを押し、`Python 3.14.x` と表示されれば成功です。

### 手順3　PDFのパスワード解除用の部品を入れる

1. キーボードの **Windowsキー** を押して「**cmd**」と入力し、**コマンドプロンプト** を開きます。
2. 次の1行をコピーして貼り付け、Enterキーを押します。
   ```
   py -m pip install pikepdf
   ```
3. 「Successfully installed」と表示されたら閉じてかまいません。

### 手順3-2　サイトからのダウンロード用の部品を入れる（スジャータめいらくなどを使う場合）

請求書をサイトからダウンロードする会社がある場合だけ、コマンドプロンプトで次の1行を実行します。
```
py -m pip install playwright
```
ブラウザはパソコンに入っている **Microsoft Edge** を使うので、ほかにインストールするものはありません。

### 手順4　ツールを置く

1. 受け取った `invoice-automation` フォルダを、**ドキュメント** など分かりやすい場所に置きます。
   （例：`C:\Users\あなたの名前\Documents\invoice-automation`）
2. 置いた後はこのフォルダを移動しないでください。移動したら手順7をやり直します。

### 手順5　設定ファイルを作る

1. フォルダの中の **`config.ini.sample`** をコピーして貼り付けます。
2. できたコピーの名前を **`config.ini`** に変えます。
   （拡張子が見えない場合は、エクスプローラーの「表示」→「ファイル名拡張子」にチェックします）
3. `config.ini` を右クリック →「プログラムから開く」→ **メモ帳** で開きます。
4. `○○` の部分を書き換えます。
   - **[ヤフーメール]**：あなたのメールアドレスとパスワード
   - **[税理士さん]**：税理士さんのメールアドレス、件名、本文
     （`{月分}` の部分は「9月分請求書」のように自動で変わります）
   - **[取引先:○○]**：請求書を送ってくる会社（下の「取引先を追加する」を見てください）
5. **上書き保存**（Ctrl + S）します。

> ⚠ `config.ini` にはパスワードが入るので、人に渡したりメールに添付したりしないでください。

### 手順6　試しに動かす

1. **`2_check_mail_now.bat`** をダブルクリックします。
2. 黒い画面に `保存: ○○.pdf` と出て、`請求書\今回送る分` フォルダに請求書が入っていれば成功です。
3. 送信のテストをします。まず `config.ini` の **宛先を自分のメールアドレス** に変えて保存します。
4. **`3_send_now.bat`** をダブルクリックし、確認メッセージで「はい」を押します。
5. 自分にメールが届き、添付ファイルが開けたら成功です。
6. ⚠ テストが終わったら、**宛先を税理士さんのアドレスに戻して** ください。テストで「送信済み」に移ったファイルは、`今回送る分` フォルダに戻しておきます。

### 手順7　毎日自動で動くようにする

1. **`1_setup_auto_run.bat`** をダブルクリックします。
2. `OK: The task 'InvoiceTool' was registered.` と出たら完了です。

これで毎日10時に自動で動きます。10時にパソコンの電源が切れていた日は、次に電源を入れたときに動きます。

## 取引先を追加する

`config.ini` の一番下に、次のかたまりをコピーして追加します。

```ini
[取引先:○○株式会社]
差出人 = seikyu@○○.co.jp
件名キーワード = 請求書
PDFパスワード =
```

| 項目 | 書く内容 |
|---|---|
| `[取引先:○○]` | 会社名。保存するファイル名に使われます |
| 差出人 | 請求書メールの送り主のアドレス。メールの「差出人」欄で確認できます。複数ある場合は `,` で区切ります |
| 件名キーワード | 件名にこの言葉が入っているメールだけを対象にします。空欄にするとその会社のメールはすべて対象です |
| PDFパスワード | 添付PDFにパスワードがかかっている場合だけ書きます。書くとパスワードを外して保存するので、税理士さんはそのまま開けます |

### サイトからダウンロードする会社（スジャータめいらく）

請求書がメールに添付されず、「請求書の準備ができました」というお知らせだけが届く会社です。ツールがお知らせメールを見つけると、サイトに自動でログインしてPDFをダウンロードします。

```ini
[取引先:スジャータめいらく]
差出人 = （お知らせメールの送り主アドレス）
件名キーワード = ご請求書準備完了
サイト = meiraku
ログインID = （サイトのログインID）
ログインパスワード = （サイトのパスワード）
```

ダウンロードの動きを目で見て確かめたいときは、`4_check_mail_show_browser.bat` を使います。ブラウザが開いて、ログインからダウンロードまでの動きが見えます。

### ヤマト運輸（Web請求書提供サービス）

「Web請求書掲載のお知らせ」などのメールが届くと、ヤマトビジネスメンバーズにログインして、**請求明細書**のPDFを `年-月_ヤマト運輸_請求明細書.pdf` という名前で保存します（年月は締め日の月）。同じ締め日のお知らせが何通届いても、ダウンロードは1回だけです。

```ini
[取引先:ヤマト運輸]
差出人 = （お知らせメールの送り主アドレス）
件名キーワード =
サイト = yamato
ログインID = （お客様コード 12桁）
ログインパスワード = （パスワード）
```

お客様コードにハイフン以降の番号がある場合は `ログインID = 082521588200-01` のように書きます。個人ユーザーIDを使っている場合は `個人ユーザーID = ○○○○` の行も追加します。

### メールのリンクからダウンロードする会社（クロスオーダーなど）

メール本文に「以下のURLよりダウンロードできます」とリンクが書いてあり、開くと「ダウンロード」ボタンがある会社です（ログインは不要）。

```ini
[取引先:OMUクリエイト]
差出人 = （請求書メールの送り主アドレス）
件名キーワード =
サイト = リンク
リンクURL = https://shop.invoice.xorder.jp/invoice/pdf/
ボタン = 請求書ダウンロード
```

| 項目 | 書く内容 |
|---|---|
| リンクURL | 本文のダウンロード用URLの、**毎回同じ前半部分**。後ろの英数字は毎回変わるので書きません。「過去の請求書」など別のリンクと区別するために使います |
| ボタン | リンク先のページで押すボタンに書いてある文字 |

同じクロスオーダーから届く会社なら、`[取引先:○○]` と `差出人` を変えるだけで追加できます。

> **サイトにログインしてダウンロードする会社について**
> 上の「サイト」に対応していない会社は、手順を教えていただいてから追加します。それまでは手動でダウンロードして、`請求書\今回送る分` フォルダに入れてください。一緒に圧縮して送られます。
> 添付ファイルのない請求書メールが届いたときは、`log.txt` に「サイトからのダウンロードが必要かもしれません」と記録されます。

## 毎月やること

**ほとんどありません。** 20日以降にパソコンを使っていると、次のようになります。

1. `今回送る分` フォルダが自動で開き、「税理士さんへ送信してよいですか？」と表示されます。
2. フォルダの中身と、メッセージに出ている件名・宛先を確認します。
3. 問題なければ **「はい」** を押します。「送信完了」と出たら終わりです。

足りない請求書がある場合は、**「いいえ」** を押してからファイルをフォルダに入れてください。翌日もう一度確認メッセージが出ます。すぐ送りたいときは、ファイルを入れてから `3_send_now.bat` をダブルクリックします。

## フォルダの中身

| ファイル | 役割 |
|---|---|
| `invoice_tool.py` | ツール本体（触らなくてOK） |
| `config.ini` | あなたの設定（パスワード入り・人に渡さない） |
| `1_setup_auto_run.bat` | 毎日の自動実行を登録します |
| `2_check_mail_now.bat` | 今すぐメールを確認します |
| `3_send_now.bat` | 日付に関係なく、今すぐ送信確認を出します |
| `4_check_mail_show_browser.bat` | ブラウザの動きを表示しながら、今すぐメールを確認します |
| `9_stop_auto_run.bat` | 自動実行をやめます |
| `log.txt` | 動いた記録。困ったときに見ます |
| `請求書\今回送る分` | 次に送る請求書がたまる場所 |
| `請求書\送信済み` | 送った請求書と圧縮ファイルの保管場所 |

## 困ったとき

| こんなとき | 確認すること |
|---|---|
| 「ログインできませんでした」と出る | `config.ini` のメールアドレスとパスワード、手順1の設定 |
| 請求書が保存されない | `差出人` のアドレスが正しいか。そのメールが「受信箱」にあるか（振り分けで別フォルダに入っていないか） |
| 「PDFのパスワード解除に失敗」と記録される | `PDFパスワード` が正しいか |
| 確認メッセージが出ない | 今日が20日より前でないか。今月すでに送っていないか（`log.txt` で確認できます） |
| `pyw.exe was not found` と出る | 手順2のPythonのインストール |
| 「サイトからダウンロードできませんでした」と出る | `ログインID`／`ログインパスワード` が正しいか。`4_check_mail_show_browser.bat` で動きを見て、止まった画面を教えてください |
| 「playwright が未インストール」と記録される | 手順3-2 |

わからないときは、`log.txt` の内容（パスワードは書かれていません）をそのまま送ってください。サイトからのダウンロードで止まったときは、止まった画面が `error_screen.png` に保存されるので、それも送ってください。
